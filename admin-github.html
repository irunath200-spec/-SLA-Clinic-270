อัปโหลดไฟล์ Excel (.xlsx) ระบบจับคู่คอลัมน์ให้อัตโนมัติทั้งหมด

เว็บไซต์ใหม่ · แยกฐานข้อมูลจากเว็บไซต์เดิม

วิธีตั้งค่าและความปลอดภัย
  1. สร้าง Supabase โปรเจกต์ใหม่ แล้วใช้ไฟล์ setup-new-supabase.sql ในโปรเจกต์ใหม่นั้น
  2. สร้างบัญชีผู้ดูแลใน Supabase Auth และเพิ่ม UUID ลงในตาราง sla_site_admins ตามคู่มือ
  3. กรอก SITE_CONFIG 3 ค่าใน HTML ทั้งสองให้ตรงกัน: supabaseUrl, publishableKey, projectRef
  4. เผยแพร่เป็นเว็บไซต์ใหม่ผ่าน HTTPS แยกจากเว็บไซต์เดิม แล้วเข้าสู่ระบบก่อนบันทึก

ใช้ Publishable Key ได้ในหน้าเว็บ แต่ห้ามใส่ Secret Key หรือ Service Role Key การซ่อนหน้า Admin ไม่ได้จำกัดสิทธิ์ ต้องเปิด RLS ตามไฟล์ SQL

Dashboard ชุดนี้อ่านข้อมูล SLA ได้แบบสาธารณะ ผู้ที่มีลิงก์/คีย์อ่านข้อมูลที่อนุญาตได้ แม้บางช่องไม่ปรากฏบนจอ หากใช้ภายในองค์กร ให้ปิดสิทธิ์ anon และเพิ่มระบบเข้าสู่ระบบสำหรับผู้ชมก่อนเผยแพร่

ยอดขาย/TA/มูลค่าสูญเสียจะถูกตัดออกจากชุดข้อมูลก่อนส่งขึ้นระบบ เก็บ TC เดลิเวอรี่ไว้คำนวณอัตรายกเลิก และคง TC รายชั่วโมงกับ AK–AO ไว้คำนวณ SLA โดยไม่เลื่อนตำแหน่งคอลัมน์

2. ผลการจับคู่อัตโนมัติ

แหล่งข้อมูลเวลา: รับ = AB, จัด = AC, รอส่ง = AD, ส่ง = AE ภายใต้หัวข้อเวลาจัดส่ง (มาตรฐาน 45 นาที) ตรวจตำแหน่งคอลัมน์ในเมนูก่อนบันทึก
สัดส่วนบิล: AK = จำนวนบิลรวม (ใช้คำนวณ), AL/AM = ภายใน 45 นาที/สัดส่วน, AN/AO = มากกว่า 45 นาที/สัดส่วน โดย AM/AO อ่านได้ทั้งเซลล์เปอร์เซ็นต์ Excel (เช่น 0.80 = 80%) และข้อความ 80% ส่วนจำนวนบิลรองรับเครื่องหมายคั่นหลักพัน เช่น 1,234 และขีด - ใน AK–AO หมายถึงไม่มีข้อมูล (ไม่นับใน AVG)
